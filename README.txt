Thanksgiving Finite Mathematics Escape Room

Unzip and open index.html in a browser.

Five rooms: linear cost functions and regression, matrices, linear programming and simplex, interest and annuities, and logic.
45-minute timer, teams of two, numeric input and validation, optional hints, final password.

To publish on GitHub Pages, upload index.html to the root of a public repository and enable Settings > Pages > Deploy from a branch > main > /(root).
